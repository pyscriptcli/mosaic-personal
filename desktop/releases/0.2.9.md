# Mosaic 0.2.9

## Notebook boards and lists

- Keep the daily tasks and notes workspace as Notebook’s default view, with new Week board and Lists views.
- Organize tasks into local lists. Create, rename, reorder, and delete lists; deleting a list moves its tasks to My Tasks.
- Move tasks between Monday–Friday dates or lists by dragging cards, or use the card’s move selector.
- Completed tasks stay available in collapsed sections. Notebook data remains in the local workspace and can use the existing optional Supabase sync. Notebook list and task management does not use ClickUp.

## Mosaic updates

- Show the current release notes in the Mosaic updates dialog when the release feed provides them.
