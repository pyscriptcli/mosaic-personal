# Mosaic 0.2.10

## Notebook boards and lists

- Keep the daily tasks and notes workspace as Notebook’s default view, with Week board and Lists views available.
- Organize local tasks into named lists. Create, rename, reorder, and delete lists; deleting a list moves its tasks to My Tasks.
- Move tasks between Monday–Friday dates or lists by dragging cards, or use each card’s move selector.
- Keep completed tasks in collapsed sections. Notebook data stays in the local workspace and can use optional Supabase sync. Notebook list and task management does not use ClickUp.

## Mosaic updates

- Show release notes in the Mosaic updates dialog when the release feed provides them.
- Include the updater’s runtime dependencies in the packaged Windows app.
